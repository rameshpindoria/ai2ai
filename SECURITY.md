# Security

AI2AI is a draft specification with a reference implementation. It has **not** had an external security review and
should not be used to protect real systems yet.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead: go to the **Security** tab of this
repository and choose **Report a vulnerability**.

Useful reports name the spec requirement (for example HAA-3 or DX-X-1) or the code path, and include steps to
reproduce. Weaknesses in the specification itself are as welcome as bugs in the code.
